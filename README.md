# PROJECT

## Summary of Patterns Applied
- Orchestrator-Worker — orchestrator drives, workers execute
- Pipeline — course → room → lecturer → policy in sequence
- Planner-Generator-Evaluator — orchestrator plans, workers generate, policy evaluates, loop if rejected
- Blackboard — the Store holds shared state
- Critic-Revision — rejection feeds back with failure context
